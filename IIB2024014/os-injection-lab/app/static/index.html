02 / THE FIX

Remove the interpreter.

The vulnerable version concatenates the filename into a command string. The shell treats ; as a command separator and executes printf next.

The secured version uses Python's hashing library. An exact allow-list also limits file access to the three teaching samples.

BEFORE · SHELL EXECUTION
command = f"sha256sum -- {filename}"
subprocess.Popen(command, shell=True, ...)
AFTER · NATIVE LIBRARY
if filename not in ALLOWED_FILES:
    return blocked_response
digest = hashlib.sha256(
    (SAMPLES / filename).read_bytes()
).hexdigest()
03

Other defenses to explain

VIVA NOTES
01 / ARGUMENT VECTOR

Keep code and arguments apart.

If a process is unavoidable, pass a fixed executable and a list of arguments with shell=False. Check for option injection too.

02 / ALLOW-LIST

Accept only expected values.

Validate on the server against a narrow set of filenames or identifiers. A blacklist of a few shell symbols is incomplete.

03 / LEAST PRIVILEGE

Limit what a process can reach.

Run as a non-root user with restricted files and network access. This reduces impact; it does not repair command construction.
